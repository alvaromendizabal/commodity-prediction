# Research operating rules

This is the existing public commodity-prediction repository. Keep its name and
visibility unchanged. The owner executes all project code, tests, notebooks,
cloud operations, Git commits/pushes/merges and submissions. An assistant may
research public sources, inspect supplied results, prepare implementations/tests
and explain instructions; it must not operate project accounts or execute
project work without new explicit authorization.

Keep experiments bounded, feature-first, leakage-safe, reproducible and
checkpointed. Never replace failed evidence with an invented pass. Preserve
raw data, environments, historical source lineages and user changes. Compare
scores only on matched evaluation scopes. Source and notebook outputs are
public after review; do not publish credentials, restricted data or model
checkpoints. See docs/PUBLICATION_SCOPE.md and docs/MANUAL_REPRODUCTION.md.

Do not silently reformat fingerprinted research modules or weaken existing
quality/publication gates. The active execution pin is not a publication branch.
Preserve earlier instructions as historical evidence, not as an override of
these current manual-execution and public-repository rules.
