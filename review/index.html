The decisions behind the system

Follow the implementation, tests, and evidence.

01 / Data science

Treat publication time as part of the feature contract.

Reject labels whose release time lies after the forecast origin instead of relying only on observation dates.

The authored timing fixture is not an official data-release simulator.

Implementation · Tests · Evidence

02 / ML engineering

Preserve checkpoint identity across interruptions.

Bind persistent research state to input and configuration identities rather than assuming a file is reusable because it exists.

The latest private training state is not included.

Implementation · Tests · Evidence

03 / Data science

Inspect where pooled accuracy breaks down.

Recompute errors by series and chronological half, retaining sample counts, bias and matched baseline errors.

These are descriptive diagnostics on authored synthetic observations, with dependent target horizons.

Implementation · Tests · Evidence

04 / Data science

Compare models on the same target population.

Use target-composition and prediction-parity checks before interpreting an apparent metric regression.

Matching a shared subset does not establish equality on different target universes.

Implementation · Tests · Evidence

05 / Data science

Publish a defensible negative conclusion.

Retain the locked assessment where the incumbent did not demonstrate an advantage over a training-only mean.

The consumed assessment is not reopened as a fresh selection set.

Implementation · Tests · Evidence

06 / ML engineering

Turn an exported result into a replayable artifact.

Regenerate the synthetic environment, recompute the output with the actual public engine, and reject stale source or altered evidence.

The receipt verifies local computational consistency, not historical private-model performance.

What the public evidence establishes.

The public commands recompute aggregate evidence and execute a synthetic delayed-label access contract. Optional browser tests exercise an online ridge demonstration using released labels only. These checks do not establish trading profitability.

Restricted market data, private prediction matrices, fitted research weights, current feature recipes, full orchestration, and operational cloud state remain excluded. Historical source credits and results are retained.

Headline signals are recorded project measurements, not results newly obtained by this review. Links point to the current default branch; the local receipt binds the exact reviewed file bytes with SHA-256. A checksum establishes consistency, not independent authentication of historical results.
