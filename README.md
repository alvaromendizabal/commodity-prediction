# Commodity Prediction

Research on multi-horizon commodity return forecasting using the MITSUI&CO. Commodity Prediction Challenge. The project prioritizes point-in-time features, purged walk-forward validation, feature-family ablations, and reproducible AWS experiments.

## Status

Project initialization is in progress. No validated model-performance result is claimed. Kaggle submissions are outside the project scope.

The planned reviewer path is data audit → exploratory analysis → feature research → modeling → validation and interpretation. Feature research must pass a documented evidence gate before final model optimization.

## Data

Obtain the dataset from [Kaggle](https://www.kaggle.com/competitions/mitsui-commodity-prediction-challenge/data) under its competition rules. Raw competition data and row-level labels are not published in this repository.
